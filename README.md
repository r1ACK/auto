# ระบบจัดตารางสอนอัตโนมัติ (Auto Timetable)

เว็บจัดตารางสอนอัตโนมัติตามโจทย์การแข่งขันทักษะเทคโนโลยีปัญญาประดิษฐ์ ระดับ ปวส. ปีการศึกษา 2568
Vanilla HTML / CSS / JavaScript + Supabase (Database + Auth) + Deploy บน Vercel (static ไม่ต้อง build)

## ฟีเจอร์

- เข้าสู่ระบบด้วย **ชื่อผู้ใช้ / รหัสนักศึกษา** แยกสิทธิ์ ครู / นักศึกษา
- **ครู**: จัดการข้อมูลครู กลุ่มเรียน ห้อง รายวิชา, นำเข้า JSON/CSV, กดประมวลผลพร้อมนาฬิกาจับเวลา, ตรวจเงื่อนไข 18 ข้อ, ดูตาราง, Export PDF, จัดการผู้ใช้
- **นักศึกษา**: ดูตารางเรียนของกลุ่มตนเอง (มือถือแสดงเป็นรายวัน) และบันทึก PDF
- Export PDF 13 ตาราง (ครู 6, กลุ่มเรียน 3, ห้อง 4) 1 ตารางต่อ 1 หน้า A4 แนวนอน มีช่องลงลายมือชื่อทุกหน้า
- ปุ่ม **คู่มือการใช้งาน** ทุกหน้า
- **Demo mode**: ถ้ายังไม่ใส่ค่า Supabase ระบบทำงานได้ทันทีโดยเก็บข้อมูลในเบราว์เซอร์ (ใช้สำรองกรณีอินเทอร์เน็ตมีปัญหา)

## ติดตั้ง

### 1) Supabase
1. สร้างโปรเจกต์ที่ https://supabase.com
2. **SQL Editor** > วางและรัน `supabase/schema.sql` แล้วรัน `supabase/seed.sql`
3. **Authentication > Sign In / Providers > Email**: ปิด **Confirm email** (ระบบใช้อีเมลจำลองจากชื่อผู้ใช้ จึงยืนยันอีเมลไม่ได้)
4. เปลี่ยนรหัสเชิญครู (ค่าเริ่มต้น `TEACHER-2569`):
   ```sql
   update private.app_secrets set value = 'รหัสใหม่ของคุณ' where key = 'teacher_invite_code';
   ```
5. **Project Settings > API**: คัดลอก Project URL และ anon public key ใส่ใน `js/config.js`
   ```js
   export const SUPABASE_URL = 'https://xxxx.supabase.co';
   export const SUPABASE_ANON_KEY = 'eyJ...';
   ```
   anon key เปิดเผยได้ เพราะทุกตารางป้องกันด้วย Row Level Security (นักศึกษาแก้ข้อมูลไม่ได้)

> ถ้าสมัครแล้วขึ้นว่าโดเมนอีเมลไม่ถูกต้อง ให้เปลี่ยน `AUTH_EMAIL_DOMAIN` ใน `js/config.js` เป็นโดเมนอื่นที่มีรูปแบบถูกต้อง

## อัลกอริทึม (สำหรับนำเสนอกรรมการ)

แบบผสม 2 ขั้น + Random Restart

1. **Simulated Annealing: จัดครูให้แต่ละวิชาของแต่ละกลุ่ม**
   ฟังก์ชันต้นทุนลงโทษ: ชั่วโมงสอนนอกช่วง min-max (หัวหน้า 18-24, ครูประจำ 18-35), ครูประจำชั่วโมงต่างกัน, วิชาเดียวกันใช้ครูหลายคน, จำนวนก้อนวิชาไม่พอให้สอนครบทุกวัน
2. **Constraint Satisfaction (Backtracking + MRV): วางคาบและห้อง**
   - ตัวแปร = ก้อนวิชา (วิชา 4 คาบ = ครึ่งวันต่อเนื่อง, 2 คาบ = ต่อเนื่อง) จึงไม่ฉีกคาบและไม่คร่อมพักเที่ยง
   - Hard: กลุ่ม/ครู/ห้องไม่ชน, เวลาไม่สะดวกของครู, วิชาคอมพิวเตอร์อยู่ห้องคอมพิวเตอร์, ลูกเสือวันพุธ 15.00-17.00 ที่สนามโดยครูที่ปรึกษา
   - MRV เลือกก้อนที่มีช่องว่างน้อยที่สุดก่อน; value ordering ให้คะแนนวันที่ครูยังไม่มีสอน (ข้อ 13) และกระจายภาระนักเรียน
3. **Random Restart** ทำหลายรอบ เลือกผลที่ละเมิดน้อยที่สุด แล้ว `evaluate()` ตรวจครบ 18 ข้อแสดงเป็นตาราง

ผลกับข้อมูลโจทย์: ผ่าน 18/18 ข้อ, ครูอภิชาต 24 ชม., ครูเมธา 30, ครูวิไล 30, ใช้เวลาประมวลผลประมาณ 0.1 วินาที

### การตีความเงื่อนไข
- ข้อ 2 "ครูทุกคน ≥ 18 ชม." ใช้กับครูที่มีกำหนดชั่วโมงในข้อมูลนำเข้า (ครูแผนก) เพราะครูสามัญสอนได้สูงสุด 6 ชม. ตามแผนการเรียน
- ข้อ 14 ใช้เวลาไม่สะดวกของครูเมธาจากตารางข้อมูลครู (จันทร์ 08-12, ศุกร์ 13-17) เป็นเงื่อนไขบังคับ ซึ่งครอบคลุมข้อ 14 อยู่แล้ว
- ข้อ 16 ตรวจว่าวิชาหนึ่งในแต่ละกลุ่มมีครูคนเดียว และพยายามให้ทุกกลุ่มใช้ครูคนเดียวกัน (ทำครบทุกวิชาไม่ได้เพราะจะเกินเพดานชั่วโมงครู)
- วิชาสามัญ (ห้อง "-") ใช้ห้องทฤษฎีก่อน ถ้าเต็มจึงใช้ห้องอื่นที่ว่าง

## วันแข่งขัน
1. ตั้งชื่อโฟลเดอร์หลัก `Vec68AI_XX` แล้ววางโปรเจกต์ไว้ภายใน
2. ตรวจข้อมูลนำเข้า / นำเข้าไฟล์จากเจ้าภาพ (เมนู นำเข้า / ส่งออก)
3. แจ้งกรรมการ > กด **เริ่มประมวลผลจัดตาราง** ครั้งเดียว > นาฬิกาแสดงเวลาที่ใช้
4. กด **Export PDF ทั้งหมด (13 ตาราง)** > Save as PDF > ลงลายมือชื่อทุกหน้า
